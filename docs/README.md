# mirabilis — документация

**mirabilis** — локальная изолированная песочница на macOS, единственная задача которой — запускать
Claude Code с полной автономией. Как воркспейс Coder на изолированной машине, но локально, в
Docker-контейнере. Философия: **KISS · open-source · личное пользование**.

Эти документы — зафиксированный результат проектной сессии: вижн, спецификация, юзкейсы и
решения. Источник истины для развития продукта.

## Провенанс (важно)

Каждое утверждение имеет источник. Метки:

- **[ВЛАДЕЛЕЦ]** — *истина*: продиктовано или объяснено **владельцем**. Не менять без него.
- **[ИИ]** — *ИИ-генерейтед*: предложено/выведено **ассистентом**, владельцем **не подтверждено**.
- **(проверено: …)** — факт, подтверждённый инструментом/документацией (со ссылкой).

Каждый раздел указывает свой провенанс по умолчанию; исключения помечены внутри. Открытые `[ИИ]`,
ждущие подтверждения, собраны в [VISION.md](VISION.md) §7 и [DECISIONS.md](DECISIONS.md) §3.

## Глоссарий

- **harness / neuro-matrix** [ВЛАДЕЛЕЦ] — протокол-надстройка над Claude (инварианты, хуки, агенты);
  отдельный репозиторий-плагин. mirabilis лишь устанавливает его как харнес и про его внутренности не знает.
- **/workspace, /tmp** [ВЛАДЕЛЕЦ] — рабочее и эфемерное пространство внутри контейнера. Внутри контейнера
  всё пишемо (I2); граница безопасности — сам контейнер и host-изоляция (I5).
- **declared list** [ИИ] (термин) — декларативный список (apt/стеки/плагины), применяемый при старте.
- **bypass** [ВЛАДЕЛЕЦ] — режим `--dangerously-skip-permissions`; инвариант I3.
- **persistent volume** — Docker-том (`~/.claude`, `~/.config/gh`), переживающий пересоздание контейнера.
