## 2. Снятые противоречия

> «Разрешение» помечено: [ВЛАДЕЛЕЦ] — выбор владельца; [ИИ] — синтез ассистента.

| # | Противоречие | Разрешение |
|---|---|---|
| T1 | root внутри vs консент-гейт | [ВЛАДЕЛЕЦ] гейта нет; защита = сам контейнер (I5), внутри root делает что угодно (I2); поведенческие лимиты — дело харнеса neuro-matrix |
| T2 | `apt` vs персистентность | [ВЛАДЕЛЕЦ] declared-list при старте |
| T3 | обновление vs живые сессии | [ВЛАДЕЛЕЦ] обновление останавливает контейнер и убивает сессии; иначе attach |
| T4 | WebFetch vs установка пакетов | [ВЛАДЕЛЕЦ] реестры в allowlist + ad-hoc |
| T5 | bypass (I3) vs диалог-согласие (I6) | [ВЛАДЕЛЕЦ] bypass не трогаем; диалога-согласия нет — граница = контейнер; поведение внутри регулирует харнес neuro-matrix, не песочница |

[ИИ]-замечание: то, что аудит назвал «противоречивыми целями», при разборе оказалось конфликтом
*реализации с целями*, а не самих целей. Цели владельца согласованы.

## 5. Переход current → target [ИИ] (из ревью критика, C1) — закрыто PR «coherent box»

I1 реализован: `bin/mirabilis` свёрнут в единственную команду → меню (обновить/войти/настройки);
подкоманды `update/down/restart/token/check` убраны; `AGENTS.md` приведён к этой реальности. Тем же PR:
единый идемпотентный entrypoint (H2), fail-fast preflight на всех путях (I7/H1/M2/M3),
Python + .NET SDK (пин 10.0) в образ и allowlist реестров (P2/F1), пиннинг RTK и single-source
`DISABLE_AUTOUPDATER` (H3/M7), удалён мёртвый `VERSION` (L3). brew-дистрибуция (P4) — отдельный следующий PR.

Затем — новое решение [ВЛАДЕЛЕЦ], отменяющее прежний консент-гейт. Внутренняя защита файлов
УДАЛЕНА целиком: нет консент-гейта (`scripts/consent-gate.sh`), нет `config/protected-paths`,
нет sandbox `denyWrite`/deny-set, нет marker-механизма и `/dev/tty`-одобрения. Граница безопасности
= САМ КОНТЕЙНЕР + host-изоляция (I5); внутри агент делает что угодно (I2, root/sudo/любые файлы),
сломал своё окружение — рестарт пересоберёт. Поведенческие лимиты (не ломать ЧУЖОЕ: push/force
в `main`, эксфильтрация кредов наружу) — дело ХАРНЕСА `neuro-matrix` (отдельный репозиторий: его
инварианты + хуки), не песочницы mirabilis. ЭНКАПСУЛЯЦИЯ: mirabilis лишь УСТАНАВЛИВАЕТ neuro-matrix
как харнес (плагин через marketplace + симлинк `~/.neuro-matrix` + append его `CLAUDE.md` в системный
промпт при запуске) и fail-fast'ит на ХОСТЕ при отсутствии харнеса/egress/Claude; во внутренности
neuro-matrix mirabilis не лезет. Конвенция папок `/workspace` СНЯТА — свободная раскладка; память
ГЛОБАЛЬНАЯ (`~/.claude` + нативный per-project контекст Claude), пер-папочной изоляции памяти нет.
